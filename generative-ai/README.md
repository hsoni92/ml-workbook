# Generative AI curriculum

Study notes for modern generative AI systems: from dense vectors through transformers, retrieval, knowledge graphs, and agents.

## How to use this track

1. Read each module's `notes/` in order (numbered files).
2. Diagrams use [Mermaid](https://mermaid.js.org/); math uses `$...$` inline and `$$...$$` for display where needed.

For **BITS trimester-3** week-based notes, regenerate indexes and Previous/Next footers with:

```bash
python3 scripts/number-notes.py
```

Generative AI modules use per-module `README.md` tables for now (flat `notes/` folders, not `week-NN` layout).
