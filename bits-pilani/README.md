# BITS Pilani coursework

Course materials organized by trimester. Public **notes**, mind maps, and sample papers live under each trimester's `notes/` directory.

Graded **assignments** and capstone work listed in [secure.yaml](../secure.yaml) are encrypted as `*.enc` in the public repo. Maintainers decrypt locally with `make decrypt` before editing, then `make encrypt` before commit.
